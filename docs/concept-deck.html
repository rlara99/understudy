Understudy · build deck01 / 13
The brief, compressed

Three modules, each with a hard bar. These come first.

1

Capture

The expert shares their screen and does a real task. A voice agent listens in a side panel and asks why at natural pauses.

RequiredAt least 3 questions, each at a pause and about something on screen. At least one is about a guardrail.

Our take: our own fake ERP reports exact field changes, so every question lands on the right moment.

2

Map

A short spoken debrief turns the session into a clickable Work Map: moment, decision, reason, guardrails.

RequiredAt least 3 new follow-ups, then a teach-back the expert confirms. Every step links to a screen moment and the expert's words.

Our take: each guardrail is also compiled into a rule the ERP can check when someone clicks Save.

3

Teach

A voice tutor watches the new hire work, explains steps the expert's way, and steps in before a guardrail breaks.

RequiredOn a case the expert never showed, catch a wrong decision before it's saved and explain it with the expert's reasoning.

Our take: cases the map can't answer go back to the expert as questions. That's the Gap Loop.

Also required in the demo: answers to the 5 "Apprentice Test" questions, and a final moonshot slide.

Understudy · build deck02 / 13
Differentiation

Most teams will build a line. We build a loop.

Most teams
Capture→Map→Teach→end

The knowledge stops growing the day the expert recorded it. When the new hire meets a case nobody showed, the tutor guesses or says nothing.

Understudy

Every case the new hire hits that the map can't answer becomes a question for the expert. A 60-second voice check-in answers it, and the map updates.

So the library grows where people actually get stuck, not where someone guessed they would.

Understudy · build deck05 / 13
Work Map JSON

One JSON file feeds the map, the tutor and the library

  1. moment: timestamp plus a frame and a clip offset, for replay.
  2. decision: what changed on screen, from the ERP's own events.
  3. reason: the expert's own words, with the time they said them.
  4. guardrails: plain-language rule plus a machine check.
  5. open_questions: what the map can't answer yet. This drives the Gap Loop.
The trick is check. During Map, Claude turns each guardrail into a simple rule the fake ERP evaluates on Save. The tutor's catch is instant and reliable, and its explanation still comes from reason.

Free stretch goal: export this file as agent instructions ("agent-ready guardrails"). About 30 minutes.

"workflow": "Supplier invoice processing",
"expert": "Sabine M.",  "confirmed": true,
"steps": [{
  "id": "s4",
  "title": "Code invoice to cost center",
  "moment": { "t": "03:12", "clip_s": 192 },
  "decision": "4711 (opex) → 0400 (capex)",
  "reason": "Equipment over €5,000 is always capex.",
  "said_at": "03:15",
  "guardrails": ["g1", "g2"]
}],

  "id": "g1",
  "text": "No asset number, no capex booking",

The 5 questions the demo must answer

Our answer to each Apprentice Test question

QuestionMechanismWhat the judge sees
1 · When to askERP keystrokes trigger sendUserActivity, which keeps the agent quiet. A pause means 3 s with no input or speech and a decision in the last 30 s. Only then does the panel send one nudge.The agent never talks over typing. It asks right after a value changes.
2 · What to askEvents are scored: changed default, hold or escalate, amount near a limit = high. Skip it if the screen already shows why. Budget: 4 live questions; the rest wait for the debrief.You moved that one to capex. What made you do that?
3 · When it understoodDebrief loops until every step has a reason and every guardrail has a stop condition. Then teach-back. The expert says yes, and the map is stamped Confirmed.A spoken correction edits the map live.
4 · New hire learnedUnseen €7,200 equipment invoice. The Save hook catches opex. A mastery panel at the end lists mastered and practice-next steps.Catch, clip replay, fix, mastery score.
5 · TrustAn "Off the record" button or spoken phrase pauses frames and transcript (shown as a gap on the timeline). Fields tagged as personal are blurred before capture, plus regex on text.A blurred IBAN in every frame and a redacted line in the transcript.

Using your ElevenLabs Creator plan

Two agents, a few client tools, and a careful minute budget

Interviewer

Curious, patient voice. Expressive Mode if your plan has it.

  • Prompt rule: speak only after a pause nudge; otherwise use the skip_turn system tool.
  • Max one question per pause, under 15 words.
  • Three modes through one dynamic variable: live, debrief, quick_ask.

Tutor

Warm and a little slower. The Work Map is loaded into its prompt when the session starts.

  • Client tools: replay_moment, flag_open_question, get_guardrails.
  • Asks the new hire to predict before it explains.
  • Quotes the expert by name: Sabine's rule is…
// panel.tsx: the 4 calls that matter
const c = useConversation({
  clientTools: { replay_moment,
                 flag_open_question }
});
await c.startSession({ agentId,
  connectionType: "webrtc" });
c.sendContextualUpdate(
  "03:12 INV-4471 cc 4711→0400");
c.sendUserActivity(); // typing
c.sendUserMessage(
  "[PAUSE] ask about last decision");
Minutes are metered on Creator. Develop with text-only sessions and short calls, and keep voice for rehearsals. Check usage in the dashboard before the final demo.

Check the SDK docs for exact signatures; they change between versions.

Demo script · about 3½ minutes, adjust to your slot

One story, two judges, one loop

0:00Hook

Sabine retires in 18 months. Lena started Monday. The 2019 process document covers almost nothing.

0:15Capture

Judge plays Sabine on 3 invoices. The agent stays silent while she types, then asks 3 questions. One is a guardrail: Is there a limit where you'd stop and ask someone?

1:15Map

Debrief asks 3 gaps, including Is the December hold for every supplier? Teach-back, one correction, then the Work Map appears.

1:55Teach

Second judge plays Lena on INV-5102 (€7,200) and picks opex. Save is blocked. The tutor asks why Sabine would stop here and plays her clip. Lena fixes it.

2:35Gap Loop

Lena opens the USD invoice. The tutor flags it, Sabine answers a 60-second Quick Ask, the badge clears, and the tutor coaches the retry.

3:05Moonshot

One slide: from one library to a living company memory.
