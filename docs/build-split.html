The three shared formats

ErpEvent { t, type, invoice, field, from, to }, where type is field_change, keystroke, save or guardrail_blocked.

WorkMap steps (moment, decision, reason, said_at), guardrails with a check rule, open_questions, confirmed.

Expert { name, title, team, topics[] }. Used for routing gap questions.

If one of these has to change, tell the other person first, then push right away.
